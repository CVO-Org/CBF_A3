[h1]Community Base Compats[/h1]

Community Base Compats (CBC_A3) is a collection of CBA compats for multiple different mod with the motivation to unify them all in a single mod.


[h1]Supported Mods[/h1]
CBC_A3 provides compatibility patches for the following mods:

[list]
    [*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3283645995]Breach - Rewrite[/url]
    [*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=1128145626]Redd'n'Tank Vehicles[/url]
    [*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=366425329]FIR AWS (AirWeaponSystem)[/url]
    [*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=1200127537]BWMod[/url]
    [*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=1369691841]Community Factions Project (CFP)[/url]
    [*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=520618345]Jbad[/url]
    [*] Vanilla Arma 3 + (c)DLCs
[/list] 

A full list can be found on Github.
